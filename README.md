# M-Pesa Business Tools
A dependency-free, mobile-first PWA for Kenyan small businesses.

## Features
- Profit calculator
- Daily sales tracker with local storage
- M-Pesa fee estimator (verify current tariffs before relying on it)
- Stock/pricing calculator
- Receipt generator with WhatsApp sharing
- Loan repayment calculator
- Installable PWA

## Run
Serve the folder with any static server. Opening index.html directly works for calculators, but HTTPS/localhost is needed for full PWA install behavior.
